# Nextflow-beginner-exercise

Overview
A hands-on, beginner-friendly repository designed to teach Nextflow fundamentals using GitHub Codespaces (no local installation required).

Learning Objectives
Understand workflow structure and execution management.

Create and run simple Nextflow processes with input/output files.

Perform basic DNA sequence analysis via command-line tools.

Exercises
Hello Languages (hello-languages/): Write a workflow, define processes, generate multi-language greeting outputs, and run it via the terminal.

DNA Sequence Analysis (dna-analysis/): Read DNA input files, validate sequences, integrate command-line tools into processes, and save results.

Getting Started
Open the repo on GitHub 
→ Click Code 
→ Codespaces 
→ Create codespace.

Navigate to the desired exercise folder in the terminal and run the workflow.
